## 🏛 Engineering Pillars

### 📋 Specification-Driven Development (SDD)
No escribo código sin un plan. Cada proyecto sigue el ciclo: **Especificación $\rightarrow$ Diseño $\rightarrow$ Implementación $\rightarrow$ Verificación**.

### 🧪 Test-First Mindset
La calidad no es opcional. Aplico la pirámide de tests y automatizo la validación mediante GitHub Actions para garantizar que el software sea reproducible y robusto.

### 🏗 Architecture & Decisions
Utilizo **Clean Architecture** para separar la lógica de negocio de la infraestructura y registro cada decisión técnica importante mediante **ADRs (Architecture Decision Records)**.
